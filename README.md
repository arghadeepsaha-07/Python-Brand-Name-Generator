# Brand_Name_Generator
# Brand Name Generator  A beginner-friendly Python command-line project that suggests brand names based on a selected business category.  ## Features  - Select AI/Tech, Food/Beverages, or Fitness. - Randomly select 10 brand names from the chosen category. - Accept category names or menu numbers as input. - Store selected brand names and categories in a JSON file. - Preserve previously saved records and avoid adding identical brand-category records.  ## Technologies Used  - Python - `random` module - `json` module  ## How to Run  1. Install Python 3. 2. Clone or download this repository. 3. Open a terminal in the project directory. 4. Run:     ```bash    python main.py    ```  5. Select a category from the menu.  ## Data Storage  The program stores generated selections in `brand_category.json`. This file is created when the program first saves results.  ## Future Improvements  - Generate original brand names by combining words. - Allow users to save only their favorite names. - Add an option to view and delete saved records. - Add automated tests and improved error handling.  ## Project Status  Beginner Python project — actively improving.
